## Скрипт для парсинга серверных логов.

Скрипт позволяет анализировать отдельный файл с логами или файлы в директории.  
Результаты анализа выводятся в терминал, сохраняются в папке results/ рядом со скриптом отдельным json-файлом для каждого файла с логами.

### Сохраняется в отчёте:
- общее количество выполненных запросов  
- количество запросов по HTTP-методам  
- топ N IP адресов, с которых было сделано наибольшее количество запросов  
- топ N самых долгих запросов  

### Установка

#### Склонировать репозиторий и перейти в директорию проекта:

```bash
git clone https://github.com/avdarya/otus-logs-analysis-avdarya.git

cd otus-logs-analysis-avdarya
```

### Использование

| Флаг           | Описание                     |
|----------------|------------------------------|
| -p, --path     | путь до файла или директория |
| -c, --top-count| количество N топ-результатов |

### Пример запуска:

```bash
  python3 log_parser.py -p='путь_до_файла/директории' --top_count=3
```
или
```bash
  python3 log_parser.py -p 'путь_до_файла/директории' --top_count 3
```
